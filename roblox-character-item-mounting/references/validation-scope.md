# 本版本的验证范围

维护日期：2026-10-21。以下是可复核的能力边界，不表示所有角色、设备或游戏都已兼容。

## 已验证

- 离线：85 条核心行为断言；标准库 unittest 包含 Luau 编译、行为夹具、原生模型源码回读和可复现打包。Luau 行为依赖已安装的 Lune；缺少时会明确跳过，不自动安装。
- Studio Edit：使用隔离 R15 夹具和不同物品名，三零件 Tool、两零件 Accessory 的预览变换能自动保存；源物品世界位置与尺寸不变。
- 恢复：新建标记可删除、Tool Grip 恢复本轮初值；等待延迟事件后不再意外回写，再次变换仍能自动同步。
- 原生插件模型：在 Studio 引擎中重新读取，三份源码与维护文件一致；当前会话插件上下文能创建工作台。
- 真实单人 Play：独立 TestEquip 示例实际发放 Tool 和头部 Accessory；实际关节与目标挂点对齐，观察到的位置误差小于 `0.00001` stud。五个物理零件均非 Anchored、不碰撞、Massless。
- Tool：实际收起、重新装备、鼠标点击 Activated；有界等待能处理原生握持关节异步生成，不依赖初装瞬间已存在关节的假设。
- 拾取：实际按键触发穿戴；重复两次后同配方仍一份，无关同名饰品和其他配方保留。
- 表现与编辑隔离：可选客户端漂浮示例发生运动；Play 中预览移除且拒绝保存，Stop 后同一姿态恢复。测试后仅清理测试夹具，原项目物品保持不变。
- 独立 AI 只读前向检查：无 MCP 的帽子操作流程已补齐独立 Play 入口；左手 Tool 请求会被正确识别为当前范围之外。

## 不应扩大声称的范围

- 自动化预览测试通过修改原生 Model 变换触发监听，不等同于逐个界面按钮、物理鼠标拖动和快捷键组合的完整人工验收。
- 未验证本地插件保存后的冷启动、完整 Undo/Redo、多客户端、R6、自定义骨架、所有角色比例、移动端或流式加载。
- 非法距离、非有限位置、冷却、禁用 Prompt、归属和并发锁拒绝主要由隔离模拟夹具覆盖，不冒充真实多人对抗测试。
- `RestorePose` 是引擎内字段恢复，不是字节备份。Attachment 赋值或网络复制可能规范化旋转矩阵；姿态应按位置/角度容差验收。需要字节级恢复时，使用原始模型文件或项目版本，并核对哈希。

实际接入时仍按[验收卡](acceptance.md)检查本项目。私人实例路径、账号与原始运行日志不随本技能发布。
