# 原始归档后的可选处理

这些分支不替代从 Xeno 到 ZIP 的主线，也不在用户只要求原始内容时自动开启。始终绑定已通过验收的输入包/hash，写独立派生目录，保留 raw。

## 素材库

`scripts/asset_library/` 提供已存在的分类、模型提取、来源校验、离线索引和打包辅助工具。Python 3.11+；实际模型/动画容器解码可能需要本机已核验的 Lune。各文件的参数以 `--help` 为准。

入口示例：

```text
python -B scripts/asset_library/organize_assets.py --archive <VERIFIED_RAW_ROOT> --output <NEW_LIBRARY_ROOT> --lune-executable <LUNE>
```

只有明确需要素材整理才执行。该入口不读取共享 JSON 自动调度，其预期输入布局包括 `snapshot/scene.rbxlx`、`inventory.json`、`download-validation.json`（后者也可位于 validation 下）；不同归档结构先适配根内路径和来源证明，不能把其他下载器的 JSON 改名冒充兼容。

按 SHA 去重，保留每个资源的来源及用途；网格文件与组装模型、rig 与实际关键帧动画分开。最大不重叠模型包便于使用，nested 模型索引仍保留。贴图的 PBR/UI/particle 用途与缺失依赖不能在分类中丢失。

输出的结构/hash验证不等于 Studio 导入或动画播放已经通过；需要实际使用时另做样本导入、映射与播放验收。素材库不恢复服务端逻辑，不执行游戏脚本，不把文件可读取解释成取得再发布许可。

## 参考源码

记录 bytecode 的原始字节、版本/编码、hash、对象路径与当前工具来源/版本，抽样确认支持后批量。第三方恢复器不随本目录分发；未知格式失败时保留原件和诊断。

结果至少分为严格恢复、合成候选、未恢复；原始 Source 与反编译结果分开。官方编译/解析通过只能说明语法等静态范围，AST 差异、二进制字符串和未覆盖函数须记录。不能恢复原变量名/注释或声称逻辑等价，更不能从客户端 bytecode补出未复制的服务端工程。

## 报错清理与静态预览

对副本逐项记录对象路径、属性、原值、新值、理由、证据和撤回方式。原始游戏 Script/LocalScript 默认停用，ModuleScript 不主动 require；独立预览代码另存、审阅并静态检查。

权限或下载失败不能自动判定某个模型在 Studio 无法使用。generic URI 预加载结果不能替代 MeshPart、字体、动画或 PBR 的实际属性/渲染验收；不能据此批量删几何。

本地资源映射按文件 hash 与实际属性支持验证。某些 PBR 组件依赖处理后的纹理数据，普通文件 URI 可能不适用；必要时在预览副本降级基础材质并说明外观变化。字体 fallback、旧 GUI、重名服务快照、动态对象和相机分别处理。

无 Avatar 的自由相机预览若被 Streaming 卸载地图，可在预览副本按需要调整；这不是所有线上游戏的性能建议。静态预览只验证新写控制入口及当前场景，不证明原玩法恢复。

## native 与 Demo

原始 `.rbxlx` 转换或 Studio 另存、编辑模式重开、资源离线部署、Play、原玩法恢复分别记录。仅选择 native 时按主工作流的独立派生参数处理，不为通过配置检查开启源码或预览。

Demo 使用新的独立试验场和新写交互代码，保留空场景基线。源素材、运行态 HUD 和模板 UI 分别溯源；导入、交互、撤回及再次导入各自有实测结果，不能借用原始包校验作运行证据。
