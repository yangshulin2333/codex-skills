# 故障分流

只读取与当前现象相关的分支。错误名称用于识别，具体包、用户、权限、路径和组件从本次设备取得。

## 连接与安装

| 现象 | 最小判断与下一动作 |
|---|---|
| 未授权 | 请用户在目标手机确认 USB 调试，随后重新检查状态；这不是 APK 安装权限问题 |
| 离线、无设备或多个候选 | 核对线缆、连接方式和明确目标；不猜设备，不默认操作列表第一台 |
| 安装命令仍在运行 | 查看手机是否停在来源确认、扫描、二次确认或身份验证；保持原会话，不重复启动安装 |
| 用户拒绝或安装中止 | 区分真实拒绝、超时和双方同时点击造成的误操作；先读取当前页面，再决定是否重试 |
| 签名冲突 | 对比已有包与候选签名，明确数据影响；不能靠任意卸载或重新签名消除冲突 |
| SDK、ABI、拆分包不匹配 | 重新选取当前系统支持的完整包组合；不要把关闭安全检查作为默认修复 |

优先使用当前环境已有工具。ADB 的目标选择、安装与 shell 参数以 [官方文档](https://developer.android.com/tools/adb) 和当前工具帮助为准。

## 商店闪退、白屏或“屡次停止运行”

1. 保存当前包版本、最新一次启动时间及相关进程/界面状态。
2. 读取该包在本次启动窗口内的崩溃堆栈。聚焦第一条有因果意义的异常与调用链，避免把早前崩溃当成修复后的新错误。
3. 按证据分支：缺失依赖、签名冲突、权限拒绝、组件版本不兼容或网络错误。白屏本身不能区分这些原因。
4. 权限拒绝时，对照当前系统机制检查实际授予状态；同样的异常文字在不同调用链下可能对应不同权限。

例如，某些系统中 `getProfileOwnerName` 调用链中的 `Calling identity is not authorized` 与管理用户相关特权有关。先查本机拒绝原因和 `MANAGE_USERS` 等相关实际授权，不能直接断言所有同名异常都缺这一权限，也不能将其写成所有手机的必需权限。

检查结果须区分：

- `requested permissions`：仅表示应用请求过。
- `granted=true/false`：对应当前包、用户和权限范围的实际状态。
- `SYSTEM`、`PRIVILEGED`、OEM 安装标记：支持判断安装机制，不单独替代目标权限检查。
- 设备管理员激活、microG 签名自检：各自证明自己的前置条件，不证明商店的全部权限。

若已选方案包含 OEM 特权安装机制，检查是否漏掉助手数据恢复、激活或安装策略步骤；先完成前置条件，再对受影响包同签名保留数据重装，观察权限是否发生预期变化。没有机制依据时不要反复尝试普通 `pm grant`，也不要轮换旧商店版本碰运气。

读取系统源码时匹配实际系统/API 和 OEM 差异；AOSP 是参考，不替代本机授予结果。[Android 权限机制](https://source.android.com/docs/core/permissions/perms-allowlist)

## 应用提示“网络异常”

分开判断以下事实：

1. 手机的一般联网状态和时间/TLS 是否正常。
2. 当前 Google 登录或商店端点能否访问。
3. 报错应用自己的服务端是否仍可用。
4. 该应用是否依赖已恢复的本地配置或初始化数据。

旧助手缺失恢复数据、远程初始化服务不可用时，也可能给出笼统网络提示。不要因此重置整部手机网络、修改已有代理或反复索取账号；按已验证方案补齐数据前置条件后再次观察。

## 登录成功但商店检索失败

先确认账号状态、设备注册/兼容状态、商店相关日志与时间网络，不删除已有账号。若证据指向旧商店缓存或旧组件残留，可在明确影响后仅重置商店本地状态，再验证；不要同时清除服务、框架与账号数据。

## 更新、下载和安装验证

- 语言资源更新与必要的安全/兼容更新分开判断。界面明确提供稍后处理且不影响当前测试时，可暂缓可选语言更新；不能把此做法扩展为长期阻止安全更新。
- 商店显示“等待中”时，查看下载与安装的实际状态、网络和必要权限。不要因按钮文字尚未刷新就重复点击安装。
- 商店详情页出现“打开”仍应交叉检查系统包管理器中的安装状态和安装来源，再实际启动应用。
- 认证、完整性、支付或特定应用不支持，不能通过关闭 Play Protect 自动解决；报告具体未通过能力。

## 控制排查成本

低成本顺序：当前状态 → 相关日志 → 前置条件/权限 → 一次针对性修复 → 验收。只有现有证据不足且结果会改变下一动作时，再做深入包分析或文档调查。

运行记录中给当前假设设定有界的尝试或时间预算，按风险和信息量调整。预算耗尽后不继续相同循环；汇总确定事实、剩余假设和可选路径。不得为寻找恢复入口就直接卸载系统备份更新、重置手机或改造系统。
